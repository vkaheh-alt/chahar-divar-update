# چهار دیوار — فایل نسخه

بازی «چهار دیوار» هر بار که باز می‌شود `version.json` را می‌خواند.

| کلید | معنی |
| --- | --- |
| `latest` | Version Code آخرین نسخهٔ منتشرشده در کافه‌بازار. اگر از نسخهٔ نصب‌شده بزرگ‌تر باشد، پیغام «UPDATE / LATER» نشان داده می‌شود (روزی یک بار). |
| `min` | پایین‌ترین نسخه‌ای که هنوز اجازهٔ بازی دارد. اگر نسخهٔ نصب‌شده کمتر باشد، آپدیت اجباری است. معمولاً `0` بماند. |
| `notes` | متن کوتاه (انگلیسی) که در پیغام نشان داده می‌شود. |

**فقط بعد از تأیید نسخهٔ جدید در کافه‌بازار** عدد `latest` را بالا ببر.
